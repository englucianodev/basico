# Luciano — Tecnologia & Engenharia

Página pessoal responsiva em português com Análise e Desenvolvimento de Sistemas, Engenharia Civil e contato pelo Instagram **@englucianodev**.

## Executar

Abra `index.html` no navegador. Para uma prévia com servidor local, execute `npx --yes serve .`.

Não precisa de instalação, compilação ou variáveis de ambiente. Os arquivos usam HTML, CSS e JavaScript puro. As fontes são carregadas pelo Google Fonts, com fontes alternativas locais.

## Publicar

Envie os arquivos para o seu repositório Git.

- **Vercel:** importe o repositório, escolha o preset **Other**, deixe o comando de build vazio e use `.` como diretório de saída.
- **GitHub Pages:** em Settings → Pages, selecione Deploy from a branch, escolha sua branch e a pasta `/ (root)`.

## Personalizar

- Conteúdo e links: `index.html`.
- Cores, layout, responsividade e animações: `styles.css`.
- Botão para copiar o contato e ano automático: `script.js`.

A página respeita a preferência por movimento reduzido e possui navegação por teclado. O contato abre o perfil do Instagram; nenhum formulário ou backend é necessário.
